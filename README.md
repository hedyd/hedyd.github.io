# Portfolio

Source for [hedyd.dev](https://hedyd.dev), my personal portfolio.

- **Site (`ui/`):** a static [Astro](https://astro.build) + React site hosted on GitHub Pages. Each project is a JSON entry in an Astro content collection.
- **Resume chat (`chat/`):** a Cloudflare Worker that answers questions about my experience using Workers AI. Its prompt is generated from the same JSON as the site, so the two stay in sync.
